# FisioSalute

Sito statico realizzato esclusivamente con Astro per lo studio FisioSalute di Erika Voltan.

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Il risultato statico viene generato nella cartella `dist/`. Il progetto non usa React, Next.js, database, autenticazione, API, Worker o componenti server.
